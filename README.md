Entry for the make.fun bounty [One Word From Your Ex](https://make.fun/bounty/u-brave-eagle-12-one-word-from-your-ex-cfd97ba2): one word my ex would use to describe me.

The word is **almost** — almost the one, almost ready, almost enough. It stings because it is true, and it lands with no explanation at all.

`main.py` (Python standard library only) writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
